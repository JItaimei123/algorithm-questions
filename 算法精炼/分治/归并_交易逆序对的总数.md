在股票交易中，如果前一天的股价高于后一天的股价，则可以认为存在一个「交易逆序对」。请设计一个程序，输入一段时间内的股票交易记录 `record`，返回其中存在的「交易逆序对」总数。

**示例 1：**

```C++
输入：record = [9, 7, 5, 4, 6]
输出：8
解释：交易中的逆序对为 (9, 7), (9, 5), (9, 4), (9, 6), (7, 5), (7, 4), (7, 6), (5, 4)。
```

用归并排序求逆序对的核心思想是：**在合并两个有序子数组时，利用"左区间当前元素 > 右区间当前元素"这一条件，一次性统计出所有逆序对**。

---

### 核心原理

归并排序将数组不断二分，直到每个子数组只有一个元素（有序）。在合并两个有序子数组的过程中，当左区间的当前元素 `nums[cur1]` 大于右区间的当前元素 `nums[cur2]` 时，因为左区间是升序的，所以从 `cur1` 到 `mid` 的所有元素都比 `nums[cur2]` 大。这些元素和 `nums[cur2]` 都能构成逆序对，数量就是 `mid - cur1 + 1`。

注意：**归并排序是自底向上的。**

`mergeSort(nums, left, mid)` 和 `mergeSort(nums, mid + 1, right)`的递归保证了

- `nums[left]` 到 `nums[mid]` 是升序的

- `nums[mid + 1]` 到 `nums[right]` 是升序的

所以只需要比较`cur1`和`cur2`的大小就可以知道有多少数比当前的数大。`cur1` 和 `cur2` 只是指向当前待比较的元素，它们后面的元素在递归过程中已经被排好序了。

```C++
class Solution {
    vector<int> tmp;
    int ans = 0;
public:
    int reversePairs(vector<int>& nums) 
    {
        tmp.resize(nums.size());
        mergesort(nums,0,nums.size()-1);
        return ans;
    }
    void mergesort(vector<int>& nums,int left,int right)
    {
        if(left >= right)
        return;
        //1.确定中间值
        int mid = left + (right-left)/2;
        //2.递归左右区间 无限二分至只有一个元素
        mergesort(nums,left,mid);
        mergesort(nums,mid+1,right);
        //3.合并两个有序数组，存到辅助数组中
        int cur1 = left,cur2 = mid+1,i=0;
        while(cur1 <= mid && cur2 <= right)
        {
            if(nums[cur1] <= nums[cur2])
            tmp[i++] = nums[cur1++];
            else
            {
            tmp[i++] = nums[cur2++];
            ans += mid - cur1 +1;
            }
        }
        //处理未遍历完的情况
        while(cur1 <= mid) tmp[i++] = nums[cur1++];
        while(cur2 <= right) tmp[i++] = nums[cur2++];
        //4.复原数组
        for(int i = left;i<=right;i++)
        nums[i] = tmp[i-left];
    }
};
```

详细分析：

### 两种情况

**情况一：`nums[cur1] <= nums[cur2]`**

```C++
tmp[i++] = nums[cur1++];
```

左区间的当前元素小于等于右区间的当前元素，不构成逆序对，直接把左区间的元素放进辅助数组，`cur1` 右移。

**情况二：`nums[cur1] > nums[cur2]`**

```C++
tmp[i++] = nums[cur2++];
ans += mid - cur1 + 1;
```

左区间的当前元素大于右区间的当前元素，说明 `nums[cur2]` 这个数和左区间从 `cur1` 到 `mid` 的**所有元素**都构成逆序对。因为左区间是升序的，`cur1` 后面的元素都比 `nums[cur1]` 大，自然也大于 `nums[cur2]`。所以逆序对数量增加 `mid - cur1 + 1`。

### 合并是从最底层开始，此时cur1和cur2所在的分组都只有一个元素

此时若发生`cur1 > cur2`则也会发生`ans += 1`这样就完成了**总逆序对数 = 左左+右右+左右**
